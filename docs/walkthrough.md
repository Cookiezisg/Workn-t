# 真桌面走查清单

有些事只有在真的 Claude 桌面版里、由真人操作才能验证：mod 自己看不到抖音页面，也不能替你点权限批准。这张清单把这些事列成一步一步的操作，每步写明“做什么”和“应该看到什么”。全部走完大约 25 分钟。

任何一步和“应该看到”不一样：运行 `/worknt doctor`，把输出和那一步的编号发出来。

## 0. 准备

1. 更新到最新版并**新开一个会话**。
2. 浏览器面板右上角 ⋯ → Keep cookies 是 **Shared**。
3. 运行 `/worknt doctor`。应该看到：`awake: true`，`errors: none`。

下面用“长活”指一个能让 Claude 干上一两分钟的任务，比如“把这个仓库的每个文件各用一句话总结”。

## A. 一个会话，从头到尾

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| A1 | 派一个长活，什么都不点 | 约 8 秒后，输入框上方出现 `刷会儿抖音？` `好` `不用`。浏览器面板没有任何动静 |
| A2 | 点 `好` | 状态带立刻变成 `正在打开抖音`；几秒后面板里出现抖音推荐流，已经在播，网站的顶栏和侧栏不见了 |
| A3 | 不点视频，直接按 ↓ | 换到下一条 |
| A4 | 动一下鼠标，点右上角 `⋯` | 出现小菜单：声音、直播、回去看看。视频没有因为这次点击暂停 |
| A5 | 在菜单里切换 `有声` / `静音` | 声音当场变化 |
| A6 | 点菜单外面 | 菜单收起，视频没有暂停 |
| A7 | 等 Claude 跑完 | 视频定格，底部出卡片 `Claude 跑完了` 和用时；状态带写着同一句话；此时按 ↓、点视频都没反应 |
| A8 | 点 `再看一条` | 接着播；这一条放完（或你划到下一条并放完）后卡片回来，按钮变成 `真的最后一条` |
| A9 | 点 `真的最后一条`，等卡片再回来 | 卡片上写 `这条也看完了。已经多看 2 条了。`，按钮变成 `你别管我了` |
| A10 | 点 `你别管我了` | 接着播，出一条 `行，这轮不管你了。`，几秒后消失。之后连看几条，卡片不再回来 |
| A11 | 点 `⋯` → `回去看看` | 视频停下，面板恢复成你点 `好` 之前的样子，状态带清空 |

## B. 走开，再回来

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| B1 | 派一个长活，点 `好`，看两三条后点状态带上的 `回去看看` | 面板恢复原样。状态带**不是**再问一遍，而是 `抖音还开着` `接着刷` |
| B2 | 点 `接着刷` | 视频立刻回来（不重新加载）。状态带的计数从 `0:00 · 0 条` 附近开始，不是接着上一轮 |
| B3 | 再点 `回去看看`，然后自己切到那个留着的抖音标签页，点进一个直播间 | 这是普通的抖音页面，没有任何 Workn't 的东西 |
| B4 | 运行 `/worknt go` | 视频页回到推荐流并开始播，不是停在直播间 |
| B5 | Claude 闲着的时候运行 `/worknt go` | 一样能开始，而且不会因为没人干活在 10 分钟后被收掉 |

## C. 两个会话

开两个会话，叫它们甲和乙，各派一个长活（乙的活更长）。

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| C1 | 在甲里点 `好` | 视频在甲的面板里播 |
| C2 | 切到乙 | 乙的状态带写 `视频开在「甲的标题」里` 和 `搬过来`；没有第二个邀请 |
| C3 | 切回甲看视频，等甲跑完而乙还在跑 | 视频不定格；页面顶部出一条 `「甲…」跑完了` 之类的提示，几秒后消失 |
| C4 | 继续看，等乙也跑完 | 视频定格，卡片标题 `都跑完了`，下面逐行列出两个会话和各自用时 |
| C5 | 点 `回去看看`。再各派一个长活，在甲里点 `好`，切到乙点 `搬过来` | 视频出现在乙的面板里；回甲看，甲的面板里那个抖音标签页已经关了 |

## D. 有会话在等你

需要一个**非自动模式**的会话（权限模式选“默认”），叫它丙。

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| D1 | 在另一个会话里看着视频；让丙跑一条需要你批准的命令 | 视频立刻定格，卡片写 `「丙的标题」在等你点头`，按钮是 `去处理` 和 `再看一条` |
| D2 | 去丙里批准 | 回来后卡片消失，视频接着播（如果还有会话在干活） |
| D3 | 在看视频的那个会话里，让 Claude 问你一个选择题 | 视频定格，卡片写 `Claude 问了你一个问题` |

## E. 没在看的时候

每一步都看状态带上的时间：它应该停住，回来后才继续走。

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| E1 | 播放中切到面板里的另一个标签页，再切回来 | 切走时暂停（没有声音），切回来继续 |
| E2 | 把浏览器面板切成别的面板（比如文件），再切回来 | 同上 |
| E3 | 用别的应用窗口把 Claude 完全盖住几秒，再回来 | 同上 |
| E4 | 自己点一下视频把它暂停，等 10 秒 | 它不会自己又播起来 |
| E5 | 播放中 5 分钟不碰鼠标键盘 | 视频暂停，卡片 `还在吗？` |

## F. 设置面板

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| F1 | 运行 `/worknt` | 打开一个面板，每个设置一行按钮，当前值是亮着的那个。**请看一眼它排得是否整齐、能不能读**，这是 mod 自己看不到的 |
| F2 | 点几个按钮（比如把“多久后问”改成 15 秒再改回 8 秒） | 亮着的按钮跟着变；在另一个会话里运行 `/worknt` 看到的是同样的值 |
| F3 | 点 `自查` | 面板下方出现和 `/worknt doctor` 一样的内容 |

## G. 直播划走

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| G1 | `⋯` 里把直播设成 `划走`，然后一直刷 | 刷到直播时，一两秒内自动换到下一条 |
| G2 | 留意有没有**普通视频**被莫名划走 | 不应该有。有的话记下大概时间，日志里记着每次是凭什么认成直播的 |

## H. Claude 碰不到视频网站

| 步 | 做什么 | 应该看到 |
| --- | --- | --- |
| H1 | 视频开着的时候，让 Claude “用浏览器打开 douyin.com 看看首页有什么” | 被拒绝，Claude 会告诉你要先 `/worknt off` |
| H2 | 让 Claude “列出浏览器里现在开着哪些标签页” | 抖音那个标签页的标题和地址显示为 `Workn’t (private)`，不是真实内容 |
| H3 | 让 Claude 在它自己的标签页里打开一个别的网站（比如 example.com） | 正常完成，你的视频不受影响 |
