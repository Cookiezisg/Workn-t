# Workn't

Claude 干活的时候，在它的浏览器面板里刷会儿视频。它先问你，全局只开一个，需要你的时候把你叫回来。

[English](README.md) · 简体中文

Workn't 是一个 [Claude Code](https://claude.com/claude-code) 的 mod，用在 Claude 桌面版里。放的是真的抖音或 TikTok 网站，登录的是你自己的账号。它从不接触你的登录，也不向任何地方发送任何东西。

## 它做什么

1. 你给 Claude 派个活。它干了 8 秒之后，输入框上方出现一行：`刷会儿抖音？`
2. 点“不用”，什么都不会发生：不加载，不播放。
3. 点“好”，视频流在后台加载，准备好了才出现在浏览器面板里，出现时已经在播。你在推荐流里的时候，网站自带的导航被藏起来。
4. Claude 跑完，视频定格，出一张卡片：`Claude 跑完了，用时 2:14`。`回去看看` 把面板恢复原样，`再看一条` 再放一条，可以要两次；第三次按钮变成 `你别管我了`，按下去这一轮卡片就不再回来。
5. 如果 Claude 停下来问你问题，或者等你批准，卡片上写的就是那件事。

也不用等它来问：`/worknt go` 现在就开始，Claude 没在干活也可以。

多个会话之间：

- **全局只有一个视频。** 不管开着几个会话，视频只在一个会话里。其他会话会告诉你它在哪，并可以搬过来。
- **别的会话的事会送到你眼前。** 别的会话跑完了，出一条小提示；别的会话在等你，视频定格并写明是哪个会话。
- **没人发起的回合不会邀请你。** 后台任务回来、定时任务触发，都不会引出任何东西。

你没在看的时候它会自己停：切了标签页、收了面板、换了会话、Claude 窗口被别的应用挡住，或者五分钟没有任何操作。

Claude 还在干活的时候你自己走开了，这个回合里它不会再问你。状态带上写着页面还开着，可以接着刷。

## 需要什么

- Claude 桌面版的 Code 标签。它依赖桌面版的浏览器面板；在终端会话里它保持休眠。
- Claude Code 2.1.330 或更新。mod 是抢先体验功能。
- 一个抖音或 TikTok 账号。
- macOS。别的系统没试过。

## 安装

在终端里：

```bash
claude plugin marketplace add Cookiezisg/Workn-t
claude plugin install worknt@worknt
```

然后在桌面版里新开一个会话。

如果你在终端里用 Claude Code，在它的输入框里敲一行也一样：`/plugin install worknt --marketplace Cookiezisg/Workn-t`。

以后更新：

```bash
claude plugin marketplace update worknt
claude plugin update worknt@worknt
```

然后新开一个会话。改了什么见 [CHANGELOG.md](CHANGELOG.md)。

## 第一次用

1. **有一个设置要你自己改。** 浏览器面板默认在退出 Claude 时忘掉登录，而且每个会话各存一份。打开面板右上角的 **⋯** 菜单，把 **Keep cookies** 改成 **Shared**。这个设置 mod 改不了。
2. **开始一次。** 给 Claude 派个活，它问的时候点“好”；或者输入 `/worknt go`。第一次会先问语言、看哪个、要不要声音。
3. **登录。** 面板里显示的是网站自己的登录界面，你自己在那里登录，登录后视频流自动开始。设成 Shared 之后，登录一次，所有会话都是登录状态。

Shared 意味着所有会话的浏览器都带着你的登录。Workn't 开着的时候，它不让 Claude 碰视频网站（见[隐私](#隐私)）；关掉之后 Claude 就能访问。

## 设置

三个入口，改的是同一份设置，对所有会话立刻生效，不用重启。

- **设置面板。** 输入 `/worknt`。每个设置是一行按钮，当前的选择亮着；下面是今天和昨天的账单，还有一个自查按钮。
- **视频页上的 ⋯。** 在右上角。视频开始时露面几秒，之后鼠标一动就出现。里面是看的时候会想改的两项，声音和直播，以及 `回去看看`。
- **命令**，见下表。

| 命令 | 作用 |
| --- | --- |
| `/worknt go` | 现在就开始摸鱼。不用等它来问，Claude 没在干活也可以 |
| `/worknt` | 打开设置面板，并显示当前设置 |
| `/worknt on` · `off` | 总开关。关掉后守卫也解除 |
| `/worknt douyin` · `tiktok` | 换片源 |
| `/worknt sound on` · `off` | 声音 |
| `/worknt live show` · `skip` | 推荐流里的直播：照常显示，或者自动划走 |
| `/worknt lang zh` · `en` | 语言 |
| `/worknt delay <秒>` | Claude 干多久之后再问 |
| `/worknt idle <分钟>` | 多久没动算走开 |
| `/worknt quiet` · `quiet off` | 今天别问 |
| `/worknt here off` · `here on` | 在当前项目里不出现 |
| `/worknt bill` | 今天和昨天的账单 |
| `/worknt doctor` | 它不对劲的时候，看它自己认为发生了什么 |
| `/worknt reset` | 清空设置、记录和日志 |

## 隐私

- **Claude 碰不到视频网站。** Workn't 开着时，模型的浏览器操作只要提到抖音或 TikTok、或者对准了处在这两个网站上的标签页，就被拒绝，不管那个标签页是谁打开的。每一步执行完还会再看一次：如果它经由没说出口的路（跳转、脚本、先跳转再读取的批量操作）落到了这些网站上，结果不交给模型。给模型看的内容里，这些标签页的标题和地址会被抹掉。守卫自己出故障时，浏览器操作一律拒绝，不放行。
- **这是一道栏杆，不是保险柜。** 守卫防的是 Claude 顺手走到、或者被网页内容带到你的视频网站上。它不是安全边界：能运行命令的模型原则上可以改掉 Workn't 自己的设置文件，就像它可以读你磁盘上的任何文件。真正的隔离靠 Claude 自己的权限设置。
- **只存在你电脑上的：** 你的设置、每天的合计（Claude 干了多久、你看了多久、几条）、状态变化和错误的日志。不存你看了什么，不存任何账号信息。
- **不向任何地方发送任何东西。**
- **不替你点任何东西。** 同意框、弹窗、网站上的任何按钮都不点。只有一个例外，而且要你自己打开：直播设成“划走”之后，它会替你按 ↓ 把直播划过去。
- **它藏了什么。** 你在推荐流里的时候，网站的顶栏和侧边导航。视频里面的东西一样不动：标签、作者、按钮都在。离开推荐流或者结束摸鱼，藏起来的立刻回来。

## 已知的限制

- 网站会改版。mod 靠页面结构认出推荐流；认不出时会原样显示网站并告诉你，而不是给你一个坏掉的布局。
- 网站可能单方面让你的登录失效（测试中发生过）。这时显示的是网站自己的登录界面，登录后自动开始。
- 没法从卡片直接跳到另一个会话，卡片上会写明是哪个。
- “直播划走”在抖音上亲眼见过它生效；在 TikTok 上还没有人看着它发生过。认不出来的直播会像普通视频一样播。
- 设置面板打开时占着浏览器面板的位置，视频会暂停，切回去就继续。
- 由本地开发预览打开的浏览器面板有自己单独的一套登录，和共享的那套不通。在这样的面板里网站显示为未登录。
- 账单只有今天和昨天。

## 它不对劲的时候

运行 `/worknt doctor`。它会打印 mod 自己认为的现状：醒没醒、每个会话在干什么、这次摸鱼进行到哪一步、最近的错误。

如果看了还是不明白，带上这段输出和你做了什么，[提一个 issue](https://github.com/Cookiezisg/Workn-t/issues/new/choose)。输出的最后一行是一个文件路径，里面有你的系统用户名；不想公开的话删掉那一行。

## 卸载

1. `/worknt reset`：结束摸鱼，关闭视频页，清空设置、记录和日志。
2. 在终端里：`claude plugin uninstall worknt@worknt`。
3. 会留下一个文件夹，因为 mod 删不了文件：`~/.claude/plugins/data/worknt`。想一点不留，自己删掉它。

## 开发

```bash
claude plugin validate .
claude plugin test .
git config core.hooksPath .githooks   # 只需一次：之后每次提交前自动跑上面两条
```

东西在哪：

- `hooks/core/`：规则，都是纯函数。`report.ts`（一个会话在干什么）、`decide.ts`（现在该发生什么）、`guard.ts`（守卫）、`page.ts`（在视频页里运行的脚本）、`sites.ts`、`copy.ts`（文案）。
- `hooks/io/`：浏览器面板和共享文件。
- `hooks/engine.ts`：把事件和定时器接到规则上。
- `hooks/register.tsx`：钩子、输入框上方的那一行、设置面板。
- `types/index.d.ts`：mod 存在会话状态里的数据的形状。

文档：

- [docs/spec.md](docs/spec.md) 是规则书。每个行为有一条带编号的规则，每个测试写明它检查的是哪条。
- [docs/audit-0.2.2.md](docs/audit-0.2.2.md) 记录 0.2.2 之前那轮大检查：怎么查的、查出什么、留下什么。
- [docs/walkthrough.md](docs/walkthrough.md) 是真桌面走查清单：只有人坐在真的桌面版前才能验证的事。
